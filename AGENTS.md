# Cardwars development

For requests to add or change 2D models, map decorations or animations, read PHASER_WORKFLOW.md first. Reuse the Phaser integration in src/phaser/map-layer.js and the shared assets/phaser/asset-pack.json. Keep new reusable assets under assets/phaser/ and inspect them with phaser-preview.html. Preserve existing map geometry, game rules, saves, pointer controls and fog of war. Do not claim a live Phaser Editor connection: this is a shared GitHub asset workflow with a Phaser runtime in the game.
